# Tabeeby — AI Healthcare Operating System

**Egypt's first comprehensive AI-powered healthcare platform.**

🏆 **1st Place, Google Developer Festival Egypt 2025** — Presented to the Minister of Health

---

## ما هو Tabeeby؟

منصة صحية ذكية شاملة تعتمد على الذكاء الاصطناعي، تتكون من ثلاثة مستويات:
- **المريض**: واجهة تفاعلية للوصول إلى خدمات صحية ذكية
- **الطبيب**: لوحة تحكم لمراقبة المرضى وتشخيص الحالات
- **الباحث**: واجهة بحث متقدمة تعتمد على RAG

## المميزات
- قاعدة بيانات 10,000+ دواء مع تفاعلات دوائية ذكية
- نظام تشخيص ذكي يعتمد على RAG (Retrieval-Augmented Generation)
- Computer Vision (U-Net + ResNet) لقراءة الأشعة السينية والتصوير بالرنين المغناطيسي والتصوير المقطعي في أقل من 8 ثوانٍ
- لوحة تحكم الطبيب تعرض 12+ علامة حيوية لـ 50 مريضًا متزامنًا
- تكامل VR/AR للعمليات الجراحية الافتراضية

## التقنية
- Python / FastAPI / Flask
- AI/ML (RAG, Computer Vision, NLP)
- PostgreSQL / SQLite
- Docker / Docker Compose

## البدء السريع
```bash
cd tabeeby-healthcare-os
cp .env.example .env
docker compose up --build
```
